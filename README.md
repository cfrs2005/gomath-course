## 使用方式

每章是独立的 JSON 内容文件（`pages/*.json`），通过 [cf-page](https://github.com/cfrs2005) 构建为静态站点。

```bash
# 构建（需要 cf-page skill）
python3 build.py wiki .

# 本地预览
open output/index.html
```
